Text Is Secretly Numbers

A character encoding is an agreed-upon table that matches every character (letters, digits, punctuation, even the space bar) with a number. The computer stores and sends the numbers; the encoding tells every device how to translate them back into text. As long as your friend's computer uses the same table, the message gets through.

ASCII: The Classic Code

In the 1960s, American engineers agreed on ASCII (American Standard Code for Information Interchange). The original version used 7 bits per character, enough for 128 characters. Here's a sample:

The table follows a tidy pattern: capital letters run 65–90 in order (A=65, B=66, C=67...), lowercase run 97–122, and digits run 48–57. A lowercase letter is always exactly 32 more than its capital.

Reminder: the character '7' is not the number 7. The digit character '7' has ASCII code 55, totally different from the binary number 7. Text and math live in different representations, which is why a program sometimes must convert digits into real numbers before doing arithmetic with them.

ASCII's Limits

ASCII was designed for English and 256 slots can't cover almost everyone else. Arabic, Hindi, Korean, Greek and hundreds of other scripts need their own letters, and modern writing needs symbols, notation, and emoji too.

For decades, different countries patched the problem with their own incompatible 256-character tables. Code 233 might mean one letter in one country's table and a totally different letter in another's, so a file made on one computer could turn to gibberish on another.

Unicode: One Table for the Whole World

Unicode solves this with a single giant table meant to include every character in every writing system. Today it assigns a number, called a code point, to more than 150,000 characters from over 160 scripts, plus symbols, accented letters, and yes, emoji.

The most common way to store Unicode is UTF-8: common English characters take just 1 byte (matching ASCII exactly, so old ASCII files still work), while less common characters take 2, 3, or 4 bytes as needed.

Why Standards Matter

A character encoding only works if both sides use the same one. If a file is saved with one encoding and opened with another, the numbers get matched to the wrong characters and the text comes out garbled. Standards are simply agreements, like driving on the same side of the road: nothing in the wiring forces it, but everyone follows the same rule so devices around the world can talk to each other.

Key Takeaways

  • A character encoding is an agreed table matching characters to numbers.
  • ASCII encodes 128 characters: capitals start at 65 (A), lowercase at 97 (a), digits at 48 (0).
  • ASCII fits English but can't hold the world's scripts, symbols, and emoji.
  • Unicode gives a unique code point to over 150,000 characters; UTF-8 stores common characters in 1 byte and stays compatible with ASCII.
  • Encodings only work when both sides use the same standard; mismatches produce garbled text.
