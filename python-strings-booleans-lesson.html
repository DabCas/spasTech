Strings

A string is a sequence of characters (letters, digits, spaces, punctuation) surrounded by quotes. Single '...' or double "..." quotes both work.

first = "Ada"
last = 'Lovelace'
greeting = "Hello, world!"
empty = ""      # an empty string is still a string

f-Strings (Formatted String Literals)

f-strings let you embed variables directly inside a string using curly braces:

name = "Mia"
age = 17
print(f"My name is {name} and I am {age} years old.")
# My name is Mia and I am 17 years old.
NOTE
f-strings start with the letter f right before the opening quote. Any expression inside {} gets evaluated and inserted into the string.

Booleans

A boolean is a value that is either True or False (capitalized in Python). Booleans come up constantly in conditions and comparisons. (Watch the video link your teacher shared before continuing.)

is_raining = True
has_umbrella = False
print(is_raining)      # True
print(has_umbrella)    # False

Boolean Operators

Combine booleans with and, or, and not:

x = 10
print(x > 5 and x < 20)    # True  (both conditions are true)
print(x > 5 or x > 100)    # True  (at least one is true)
print(not x > 5)           # False (reverses True to False)
⚠ COMMON ERROR
= vs ==: A single = assigns a value. A double == checks equality. Writing if x = 5: is a syntax error in Python. Always use == for comparisons.

Checking the Type with type()

The built-in type() function tells you what type a value is:

print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>

This is super handy when you are debugging and something behaves unexpectedly.
