Reading Input from the User

The input() function pauses your program and waits for the user to type something and press Enter. It always returns the typed text as a string.

name = input("What is your name? ")
print("Nice to meet you, " + name + "!")
IMPORTANT
input() always returns a string. Even if the user types 42, Python stores it as the string "42", not the number 42. This is the most common beginner mistake when doing math with user input.

Type Conversion Functions

FunctionWhat it doesExample
int()Converts to an integerint("42") → 42
float()Converts to a floatfloat("3.14") → 3.14
str()Converts to a stringstr(100) → "100"

The pattern int(input()) is so common you'll use it constantly:

age = int(input("Enter your age: "))
print("Next year you will be", age + 1)

Without the int() wrapper, age + 1 would crash with a TypeError because you can't add a string and a number.

Common Conversion Errors

ValueError — invalid literal:

x = int("hello")   # ValueError: invalid literal for int()

If the string doesn't look like a valid number, Python raises a ValueError. Always make sure the user typed something numeric before converting it.

TypeError — wrong operation on incompatible types:

raw = input()
print(raw + 10)   # TypeError: can only concatenate str (not "int") to str

Here raw is a string, not an int. You must convert first: print(int(raw) + 10)

⚠ COMMON ERROR
String + Number = TypeError. Python refuses to silently combine different types the way some other languages do. Convert explicitly with int(), float(), or str() depending on what you need.

The Difference Between + and + (string vs number)

This is subtle but important:

a = "5"
b = 10
print(a + a)          # "55"  (string concatenation)
print(int(a) + b)     # 15   (numeric addition)

Both lines use +, but the type of the operands decides what happens. With strings, + joins them. With numbers, + adds them.

Converting Between Numeric Types

You can convert freely between int and float:

x = 7
print(float(x))   # 7.0
y = 3.9
print(int(y))      # 3  (truncates, does NOT round!)
NOTE
int() truncates, it does not round. int(3.9) is 3, not 4. If you want rounding, use the built-in round() function.
