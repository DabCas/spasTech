Two Bumpers, Smarter Turns

Last time, one bump switch always made the robot turn the same way. Today it gets a second bumper — so it can turn away from whichever side got hit.

10 minStep 1: Mount it
5 minStep 2: Predict
15 minStep 3: Program
10 minStep 4: Test & fix
New idea: if / else. Before, your robot only knew "a bump happened." Now it needs to know which bumper fired, and choose a different action for each one. That choosing is called a branch — in code it's an if / else block: "if this happened, do A — otherwise do B."

1 Mount the second bumper

Your current bump switch is centered on the front. For this activity you want one bumper on each front corner, angled slightly outward, so each one only trips when that side hits something.

Top-down view. If your existing bumper is actually on the right, just swap the labels — the important part is one on each corner, angled outward.

Careful: if the two bumpers overlap or point straight forward, a head-on hit will trigger both at once — which is actually fine and expected (see the Challenge at the end), but a corner hit should only trigger one of them.

2 Predict

The robot drives forward. Something hits Bumper A (left side). What should the robot do next: turn toward the left, or away from it, toward the right? Why?

3 Build the program

Build it in two parts. The new if / else block is outlined in green.

Part A: Drive until either bumper is pressed (like last time, but now checking two sensors)

when started
set drive velocity to 50 %
forever
drive forward
wait until Bumper A pressed? or Bumper B pressed?

Part B: Decide which way to turn

when started
set drive velocity to 50 %
forever
drive forward
wait until Bumper A pressed? or Bumper B pressed?
stop driving
drive reverse for 150 mm
if Bumper A pressed?
turn right for 90 degrees
else
turn left for 90 degrees
Read it like a sentence: "If Bumper A was the one pressed, turn right. Otherwise (it must have been Bumper B), turn left." The robot always turns away from whichever side got hit.

5 Challenge: The head-on hit

If the robot drives straight into a wall dead center, both bumpers might press at almost the same moment. Right now, your if / else only checks Bumper A — so a double-hit still just turns right, as if only A were pressed.

Try it: Add a check before the if/else: "if both Bumper A and Bumper B are pressed, turn all the way around (180 degrees) instead of just 90." This is a good use of a third branch — ask your teacher about elif ("else if") if you want to try stacking more than two choices.
